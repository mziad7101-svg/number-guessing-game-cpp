# Number Guessing Game (C++)

A simple C++ game where the user tries to guess a hidden number.

## Features
- User input
- Loop control
- Conditional statements
- Interactive gameplay

## Concepts Used
- C++
- Loops
- Conditions
- Input / Output

Guess the number: 9
